# Prévia do convite — Denner & Nágila

12 de dezembro de 2026, às 16h — Sítio Paraíso, Nerópolis.

Esta é uma prévia estática para avaliar o visual e os textos. O formulário está desativado e não envia nem armazena dados. Não contém painel, banco, senha ou confirmações. A versão completa anterior continua sendo um projeto separado.

## Publicar no GitHub Pages

1. Crie um repositório público chamado `convite-denner-nagila`. Pode marcar Add README.
2. Extraia este ZIP. No repositório, escolha Add file > Upload files (em um repositório vazio, clique em uploading an existing file).
3. Envie os arquivos extraídos, não o ZIP nem a pasta inteira. index.html deve aparecer diretamente na raiz do repositório junto com style.css, config.js e app.js. Salve em Commit changes, na branch main.
4. Acesse Settings > Pages. Em Source, selecione Deploy from a branch. Em Branch, escolha main e /(root). Clique em Save.
5. Aguarde a publicação. Na mesma tela, clique em Visit site e copie esse endereço para enviar à Nágila.

O site será público. O endereço terá o formato https://SEU-USUARIO.github.io/convite-denner-nagila/ (substitua SEU-USUARIO pelo login real). O link oficial aparece em Settings > Pages. A publicação pode levar até 10 minutos. O arquivo .nojekyll desativa o processamento Jekyll; se não aparecer no seletor de arquivos do Windows, esta prévia também usa nomes compatíveis com o processamento padrão.

Não precisa instalar Node, npm, Firebase ou Angular para publicar esta prévia. Para trocar dados, edite config.js e envie o arquivo atualizado. Fotos/músicas futuras devem usar caminhos relativos, como ./fotos/casal.jpg, e os arquivos precisam ser enviados também.

A capa criada no Photoshop foi separada em camadas: `assets/capa-base.webp` guarda o papel e os nomes, enquanto `assets/folhas-superiores.webp` e `assets/folhas-inferiores.webp` preservam a transparência e recebem um movimento suave no site. `assets/capa-casamento.webp` é a composição estática usada no fundo desfocado. `assets/laco-inicial.webp` mostra o laço fechado e `assets/laco.webm` contém a animação transparente. Todas usam 1080 × 1920 px. O texto “TOQUE PARA ABRIR” é texto do site, com animação discreta, e toda a capa pode ser tocada. Ao tocar, o laço se desfaz; o convite só abre quando o vídeo termina. Para trocar o laço ou seu tempo depois, substitua os dois arquivos mantendo os nomes e as dimensões — o site aguarda automaticamente a nova duração.

Nome do local, mapa, data, horário e contagem estão configurados. Prazo de confirmação, traje e dados de presentes ainda aguardam preenchimento.
